MII'S COMMISSIONS — Y2K COMMISSION WEBSITE

This folder contains the complete website.

IMPORTANT:
- Keep index.html, angelica.ttf, and all PNG/WEBP/JPG assets in the same folder.
- The Angelica font is bundled locally, so it does not depend on an online font service.
- The order form is your Google Form embedded in the ORDER section.
- If the embedded form does not load, the page provides a direct Google Forms link.

To publish: upload the whole folder to your web host (for example GitHub Pages, Netlify, or another static host).
